# LessonLoop

LessonLoop helps schools activate more teachers through guided trials, classroom engagement tools, and clear conversion analytics.

## Stack

- Nuxt 3 frontend
- NestJS backend
- Prisma with SQLite for local development
- Shared TypeScript package for cross-app contracts

## Getting started

```bash
npm install
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

The API runs on port 3001 and the web app runs on the port selected by Nuxt.
